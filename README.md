# 📚 Previsão de Churn de Escolas

> Prevê quais escolas/clientes de uma editora não vão renovar a adoção de livros didáticos. Identifica risco de cancelamento com meses de antecedência e recomenda ações de retenção personalizadas por escola.

**🌐 Demo ao vivo (web app interativo):** https://jhondados.github.io/editora-churn-escolas/

## 📊 Resultados-chave (KPIs)
**0.93** AUC-ROC · **+31%** Retenção · **R$ 24M/ano** Receita salva · **4 meses** Antecip.

## 🧠 Tecnologias de IA
Machine Learning · Survival Analysis · SHAP · Churn Prediction

## ✨ O que faz
- Score de churn por escola/rede
- Top fatores de risco (SHAP)
- Ação de retenção recomendada
- Priorização da carteira comercial
- Previsão de receita renovável

## 🗄️ Fonte de dados real
[FNDE/PNLD + CRM editorial](https://www.fnde.gov.br/programas/programas-do-livro)

## ⚙️ Como funciona
1. **Coleta de dados reais** — integração com FNDE/PNLD + CRM editorial
2. **Processamento com IA** — Machine Learning · Survival Analysis · SHAP · Churn Prediction
3. **Dashboard & insights** — KPIs, gráficos e recomendações acionáveis
4. **Ação automatizada** — alertas, predições e decisões em tempo real
